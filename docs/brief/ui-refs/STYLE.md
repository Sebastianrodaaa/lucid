# Night arcade

The local style pack named in the brief was not on the build machine; this is the style as specified.

- Cabinet background deep plum-black `#120A1A`. Panels one step lighter, thin 1px borders, no shadows except the phosphor glow on screens and lamps.
- Phosphor mint `#7CFFB2`: lucid's screen and every legal lamp. Dusty rose `#E58FA6`: only the one-pass baseline and its smears.
- One lilac ramp `#2A1F3D` to `#C9B6FF` for loop counts (ring segments, filmstrip, legend). Nothing else uses lilac.
- Syne for the name and headings; IBM Plex Mono for every counter, label and axis. No serif.
- Layout: arcade cabinet. Two large square screens centered, loop ring around lucid's screen, full-width filmstrip below, histogram and counters in a slim bottom bar. No sidebar. The results page uses the same cabinet.
- Pro data dashboard manners: small uppercase labels, thin borders, data front and center.
